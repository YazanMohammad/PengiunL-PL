# Penguin Launcher v0.1.0 — Windows x64 preview

Initial downloadable **prerelease**. This is experimental software, not a production-ready or security-certified release.

## Included

- Minimalist dark game library, grid/list views, search, filters, sorting, density controls, game details, and persistent actions.
- Existing Steam, Riot, Epic, and EA discovery/profile/session adapters; vendor launch handoff and account-selection preflight.
- Authenticated loopback-only local API and automated backend/frontend regression coverage.
- Full README for installation, usage, development, storage, troubleshooting, and known limitations.

## Download

Use `PenguinLauncher-v0.1.0-win-x64.zip`, not GitHub's automatic source archives. Compare its SHA-256 with `SHA256SUMS.txt`, extract everything, and run `PenguinLauncher.exe` as a normal user. Keep `wwwroot` beside the executable.

The ZIP includes the .NET runtime and third-party notices. Microsoft Edge WebView2 Runtime is a separate prerequisite. Windows x64 only; Linux/macOS/ARM64 packages are not included. The binary is unsigned, with no automatic updater or installer.

## Safety and known limitations

Account operations can forcibly stop launcher processes and modify session/configuration files. Session backups are not encrypted. Back up `%APPDATA%\PenguinLauncher` and relevant vendor files independently, save work, and prefer isolated/test profiles. Do not use unsafe/manual path-like account identifiers.

**Play and Install can automatically switch sessions**, even with a single associated account and no account-choice prompt; this can forcibly stop clients/running games. **Logout acts immediately without confirmation.** Removal can affect vendor configuration, including Steam's `loginusers.vdf`, not just app backups. Capture success is not proof of a valid vendor login.

Account-ID/backup containment, transactional persistence, serialized recovery, safer command launching, exception redaction, and other hardening work remain incomplete. Game/account associations are not proof of ownership. Vendor compatibility, reauthentication, and MFA behavior can vary. This prerelease is not a trusted credential vault.

Automated tests and package checks do not certify native window/session reload, successful real vendor mutations, exhaustive accessibility, or compatibility on another Windows machine. Existing formatter failures and frontend dependency advisories remain. Consult the README and dated verification report for exact evidence; no broader security claim is made.

No production application behavior is changed by this documentation/packaging task. No automatic release pipeline, new application license, or signing setup is added.
